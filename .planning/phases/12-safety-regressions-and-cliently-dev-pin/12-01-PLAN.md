## Goal

## Test conventions (read before authoring tests)

This codebase does **not** use Vitest. Tests are hand-rolled:
- File lives **alongside** source (`hydrate.ts` → `hydrate.immutability.test.ts`), not under `__tests__`
- Hand-rolled `assert(cond, msg)` + `console.log` / `console.error` with `passed` / `failed` counters (copy the pattern from `architect.test.ts` lines 6-31)
- Each test file ends with `process.exit(failed === 0 ? 0 : 1)`
- Tests are added to `packages/core/package.json` as new `test:<name>` script entries that `tsx` the file directly
- Package name is `@agent-os/core` (not `@acqu-os/core`)
