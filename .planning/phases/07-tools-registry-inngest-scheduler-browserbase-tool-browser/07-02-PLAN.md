<objective>
Extend `seedAgent` and `Bundle` to treat tools as first-class bindings — same shape and lifecycle as skills and mcps. Tools are referenced in AgentSpec by `{ key, name }`, ensured-or-created in the registry per (tenant, key), then bound to the agent via the `agent_tools` join. Bundle assembly reads the join and populates `bundle.tools[]` so the runner can later consume it.

Purpose: This is the "agents-as-data" rule applied to tools (CLAUDE.md non-negotiable #1). After this plan, any seed script can add `tools: [{ key: 'tool.browser', name: 'Browser' }]` to its AgentSpec and the binding is automatic.
Output: Existing 26+ seed scripts still pass; new tools field works end-to-end.
</objective>
