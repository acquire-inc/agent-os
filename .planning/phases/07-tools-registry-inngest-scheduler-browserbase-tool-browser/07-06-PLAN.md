<objective>
Wire the runner to honor the `tools` registry: set `options.allowedTools` explicitly from `bundle.tools[].key` (Pitfall 5 — without this, the SDK is wide-open and the registry adds zero enforcement), register a custom-tool handler for `kind='custom'` tools that dispatches to `@agent-os/tool-browser`'s `runBrowserTool`, and save large outputs to a file per CLAUDE.md non-negotiable #4. The existing PreToolUse autonomy gate continues to fire on `tool.browser` invocations with zero hook code changes.

Purpose: This is the runner-side half of Sub-feature §3. The other half (the workspace package) shipped in Plan 05. After this plan, `tool.browser` is callable end-to-end as long as an agent has the binding.
Output: A runner that enforces the tools registry as a real allowlist and dispatches the first custom tool.
</objective>
