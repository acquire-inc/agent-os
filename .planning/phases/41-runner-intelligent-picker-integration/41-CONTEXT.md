# Phase 41 — Runner integration of the intelligent picker

Replaces Phase 33's tier-only per-skill `model.routed` emission with `pickModelIntelligently()` calls against the live catalog. Per-tool dispatch (Phase 32) gets the same upgrade. Skills/tools with a `task_profile` JSON now go through the value-per-dollar scorer; ones with only a `preferred_model_tier` fall through to the Phase 32 tier fork; ones with neither use the agent baseline. Adds `apps/runner/src/catalog.ts` (in-process 5-minute cache over `loadModelCatalog`) and `packages/db/src/model-catalog.ts` (`makeReservationPersister`-style factory). The emitted `model.routed` events now carry `source` (catalog_picker | tier_fork | agent_baseline) and `top_alternatives` (top 3 with value/capability/cost scores), giving the operator full pick rationale in the audit trail.
